# 📜 论文助手 — 毕业论文通关工具

Dark Academia风格的毕业论文助手。**参考文献格式化 (GB/T 7714-2015)**、格式检查清单、进度管理、致谢生成、答辩准备 — 五个模块覆盖从开题到答辩的全流程。

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| 📚 **参考文献格式化** | 支持6种文献类型 (J/M/D/C/EB/P)，自动生成GB/T 7714-2015标准引用，一键复制/导出 |
| ✅ **格式检查清单** | 7大类共30+项检查，覆盖封面、摘要、正文、图表、参考文献等 |
| 📊 **进度管理** | 9个阶段可视化追踪，答辩倒计时，整体进度百分比 |
| 💌 **致谢生成器** | 4种风格（温暖/正式/简洁/文艺），填写信息一键生成 |
| 🎤 **答辩准备** | PPT大纲（8页结构）、8个高频问题+回答思路、答辩倒计时 |

## 🚀 部署

### GitHub Pages（免费，推荐）
```bash
# 1. 将整个 thesis-helper 文件夹上传到GitHub仓库
# 2. Settings → Pages → Source: main branch → Save
# 3. 等待1分钟，访问 https://你的用户名.github.io/仓库名
```

### Vercel（免费）
1. 注册 [vercel.com](https://vercel.com)（GitHub登录）
2. Import你的GitHub仓库 → Deploy
3. 获得 `https://项目名.vercel.app` 域名

### 本地运行
```bash
python -m http.server 8080
# 访问 http://localhost:8080
```
